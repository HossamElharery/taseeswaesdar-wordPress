# 🏢 مجلد اللوجو - Logos Folder

## 🎯 هذا المجلد مخصص للوجو الخاص بالشركة

### أنواع اللوجو التي يمكن وضعها هنا:

1. **اللوجو الرئيسي** (Main Logo)
   - `logo.png` أو `logo.svg`
   - للاستخدام في Header

2. **لوجو الجوال** (Mobile Logo)
   - `logo-mobile.png`
   - نسخة أصغر للشاشات الصغيرة

3. **لوجو Footer** (Footer Logo)
   - `logo-footer.png`
   - للاستخدام في تذييل الصفحة

4. **لوجو Favicon** (Favicon)
   - `favicon.ico` أو `favicon.png`
   - الأيقونة الصغيرة في المتصفح

---

## 📝 كيفية استخدام اللوجو:

### بعد وضع اللوجو هنا:
1. أخبرني: "استبدل اللوجو بـ logo.png"
2. سأربطه تلقائياً في الكود
3. سيظهر في الموقع فوراً

---

## ✅ أفضل الممارسات:

- استخدم PNG بشفافية للوجو
- أو SVG للحصول على جودة أفضل
- احرص على أن يكون اللوجو واضحاً حتى في الأحجام الصغيرة
